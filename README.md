# Basic React App (Vite)

Minimal React app scaffolded with Vite.

## Setup

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Files added:

- package.json
- vite.config.js
- index.html
- src/main.jsx
- src/App.jsx
